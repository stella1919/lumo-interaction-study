# Optional visual assets

The demo works without these files because its AR bridge, lights, seagulls, and
particles are drawn on Canvas. To replace the fallbacks, add:

- `bridge-glow.png`
- `seagull-1.png`
- `seagull-2.png`
- `golden-gate-background.jpg`
- `golden-gate-background.mp4`
- `lumo-logo.png`
